# 나인 이닝즈 · 커리어 야구 시뮬레이터

고교 3학년부터 드래프트, 퓨처스리그, 1군, 부상, FA, 포스트시즌, 은퇴까지 진행하는 브라우저 기반 싱글 플레이 게임입니다.

## 실제 플레이 방법

1. GitHub에서 feature/realistic-season-v1 브랜치를 선택합니다.
2. Code → Download ZIP으로 저장소를 내려받고 압축을 풉니다.
3. index.html 파일을 Chrome 또는 Edge에서 엽니다.
4. 새 커리어 시작 → 이름/포지션 → 고교 시즌 → 드래프트 → 프로 입단으로 진행합니다.
5. 홈 화면의 목표와 훈련을 정한 후 시즌 시작 버튼을 누릅니다.
6. 브라우저의 로컬 저장소에 진행 기록이 저장됩니다. 같은 브라우저의 이어하기로 복귀할 수 있습니다.

## 현재 개발 브랜치 개선

- 포수/1루수/2루수/3루수/유격수/좌익수/중견수/우익수/지명타자/선발/불펜/마무리 12개 역할 전용 플레이 상황
- 각 상황에서 3가지 전략, 능력치에 따른 성공/실패와 장기적인 포지션 자신감, 플레이 기록
- 포수/외야수에게 내야 병살 및 시프트 이벤트가 노출되지 않게 제한
- 선발, 불펜, 마무리 투수에게 맞는 이닝과 등판 상황 표시
- 홈런, 안타, 타수 및 장타 기록의 일관성 보정
- 투수 이닝을 야구식 6.1 = 6이닝 1아웃으로 취급
- 포스트시즌 경기별 시리즈 방식, 수상 및 규정타석 개선
- 상시 야구장 배경, 드래프트/데뷔/부상/FA/우승에서만 등장하는 주요 장면 이미지
- GitHub Actions에서 포지션 및 기록 일관성 6개 그룹 자동 검사

## 2026-10 플레이 피드백 반영

- **해외 이적 시스템 임시 제거**: 해외 진출 목표, 스카우트 이벤트, FA 해외 이적 선택지 비활성화. 실제 해외리그 구단이 준비되기 전까지 존재하지 않습니다. 기존 세이브의 옛 해외 목표는 기본 목표로 교체합니다.
- **스토리 진행**: 한 시즌 4~5개 직접 선택. **간편 진행**: 1~2개 직접 선택. 병역과 수술 등 반드시 사용자가 결정해야 하는 이벤트는 예외적으로 추가될 수 있습니다.
- **포지션별 경기**: 12개 역할의 원래 장면과 24개 추가 장면, 압박 상황/날씨/컨디션 등으로 같은 선택이라도 결과가 변합니다. 포지션에 맞지 않는 수비 상황은 제공되지 않습니다.
- **선수 능력치**: 홈의 선수 카드에서 5가지 능력치를 수치와 막대로 확인하고 성장 탭에서 집중 훈련 능력치를 선택할 수 있습니다. 자동 추천으로 복귀할 수 있습니다.
- **라이프 탭**: 보유 금액, 통산 수입, 사용 금액이 표시됩니다. 투수/야수별 장비, 고급 시계와 스포츠카 및 별장 등 귀중품, 여가/기부/팬미팅/여행 등 21가지 상품/활동을 구매할 수 있습니다. 장비 중복 구매 불가, 활동은 시즌당 1회. 소비 효과는 실제 스탯과 팬 여론, 시즌 분위기에 적용됩니다.
- **팬 커뮤니티**: 숫자 여론 게이지 대신 시즌 종료와 계약 결과에 따라 3~6개의 기사 댓글 스타일 반응을 생성해 보관합니다. 시즌 내용, 플레이 및 구단 결정에 따라 긍정과 비판이 갈립니다.
- **화면 재배치**: 홈에 시즌 준비와 최근 댓글, 선수 카드에 능력치와 잔액, 성장 탭에 상세 훈련, 라이프 탭에 소비 및 활동, 커리어 탭에 댓글 기록을 배치했습니다. 글씨 크기, 글자 굵기, 카드 간격, 탭바도 정리했습니다.

### 주의사항

이전 플레이의 통산 수입을 바탕으로 기존 세이브의 지갑 잔액을 초기화하며, 새 게임은 0원에서 시작해 계약금 및 시즌 연봉을 받으면 잔액이 늘어납니다. 기존 기록과 업적을 초기화하지 않습니다.
이벤트는 시즌 단위 확률로 처리되므로 같은 전략이라도 성공을 보장하지 않습니다. 신규 이벤트 이미지를 전부 자동으로 연결한 버전은 아닙니다.

### 플레이 팁

1. 선수 생성 후 프로 입단.
2. 홈에서 시즌 목표, 훈련 계획, 스토리/간편 모드 선택.
3. 성장 탭에서 집중 훈련할 능력치 선택, 라이프 탭에서 필요한 장비 또는 활동 구매.
4. 시즌 시작 후 포지션에 맞는 이벤트 직접 선택.
5. 시즌 종료 결과와 팬 댓글, 수상 및 FA/연봉 협상을 확인하고 다음 시즌으로 진행.

## 이미지 적용

기존 기본 SVG 일러스트는 삭제했습니다. 이제 assets/images/ 아래에서 원하는 그림을 직접 관리합니다.
- assets/images/backgrounds/stadium.webp : 상시 배경
- assets/images/events/draft.webp, debut.webp, injury.webp, contract.webp, champion.webp : 해당 주요 이벤트 발생 시 표시
- assets/images/players/ : 향후 선수 프로필 이미지용 (현재 자동 연결되지 않음)
- assets/images/teams/ : 향후 구단 로고 이미지용 (현재 자동 연결되지 않음)
- events/training.webp, batting.webp, pitching.webp 등 그 외 이미지도 저장 가능하지만 아직 해당 화면에는 자동 연결되지 않습니다.

아직 올리지 않은 이미지 경로는 건너뛰며, 깨진 기본 일러스트나 대체 이미지를 표시하지 않습니다.
업로드 방법과 정확한 이름은 assets/images/README.md를 참조하세요.
이전에 받은 이미지 ZIP의 파일을 사용할 경우 stadium.webp는 backgrounds/ 안에, 이벤트 이미지는 events/ 안에 올려야 합니다.

## 중요한 미완료 범위

현재 시즌 기록 엔진은 시즌 단위 확률 계산을 사용합니다. 이닝/타석/수비/주루를 완전한 경기 단위로 연결한 엔진과 지속 NPC 로스터는 아직 구현되지 않았습니다.
새 기능은 기존 시즌 시뮬레이터 위에서 동작하며, 모든 플레이어와 구단의 일치된 경기 결과에 의해 기록/순위가 발생하는 수준은 아닙니다.
브라우저에서 신인부터 은퇴까지 장시간 전체 플레이하는 E2E 시험과 시즌 진행 중 새로고침 복원도 추가 검증이 필요합니다.
